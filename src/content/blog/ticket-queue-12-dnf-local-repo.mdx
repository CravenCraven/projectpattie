<p><span class="c-light">The ticket:</span> dev1 wants <code>htop</code>, <code>tree</code>, <code>nmap</code>, <code>bind-utils</code>, and the Development Tools group installed. And, because a hardened replica is going into a DMZ next month with no internet repos, they want a local DNF repository built now from a directory of RPMs, with the workflow documented. Bonus: figure out which package owns <code>/usr/sbin/sshd</code>.</p>

<p><span class="c-light">The real problem:</span> installing packages is easy. Building a working repository from scratch is the part the exam tests, and it is the part that saves you when there is no internet.</p>

<p><span class="c-light">What we are doing:</span> using <code>dnf</code> and <code>rpm</code> confidently, then building and testing a local repo.</p>

<h2 id="mirror" class="pp-h2">Build the local repo mirror</h2>

<p>This is the exam scenario. Install the repo tool, download RPMs into a directory without installing them, generate the metadata, then write a repo file that points at the directory. Finally, prove you can install from that repo alone.</p>

<div class="pp-code"><div class="pp-code-head"><div class="pp-code-dots"><div class="pp-code-dot"></div><div class="pp-code-dot"></div><div class="pp-code-dot"></div></div><div class="pp-code-lang">bash</div><button class="pp-code-copy" onclick="navigator.clipboard.writeText(this.closest('.pp-code').querySelector('pre').textContent);this.textContent='copied!';setTimeout(()=>this.textContent='copy',1500)">copy</button></div><div class="pp-code-body"><pre>{`sudo dnf install -y createrepo_c\nsudo mkdir -p /srv/repo_mirror\n\n# download RPMs plus dependencies without installing\nsudo dnf install -y --downloadonly --downloaddir=/srv/repo_mirror htop tree\n\n# generate the repository metadata\nsudo createrepo /srv/repo_mirror/\n\n# write the .repo file pointing at the directory\nsudo bash -c 'cat > /etc/yum.repos.d/server1-local.repo << "EOF"\n[server1-local]\nname=Server1 Local Mirror\nbaseurl=file:///srv/repo_mirror\nenabled=1\ngpgcheck=0\nEOF'\n\nsudo dnf clean all\nsudo dnf repolist    # server1-local should appear\n\n# prove it: install using ONLY the local repo\nsudo dnf remove -y tree\nsudo dnf --disablerepo='*' --enablerepo='server1-local' install -y tree\nrpm -q tree`}</pre></div></div>
