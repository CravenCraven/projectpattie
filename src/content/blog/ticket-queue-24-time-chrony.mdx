<p>auditor1 opened this one because server1's clock is running four minutes fast, and four minutes is plenty to make the audit logs useless: you cannot line an event on this box up against the same event on another box when the timestamps disagree. So the clock has to genuinely sync, via chrony against <code>time.cloudflare.com</code> and <code>pool.ntp.org</code>, the timezone has to read America/New_York, and the hostname and locale get confirmed while you are already in there.</p>

<p>None of this is hard once you know which tool owns which setting, and that is the real content: <code>chronyc</code> for the sync, <code>timedatectl</code> for time and timezone, <code>hostnamectl</code> for the name, <code>localectl</code> for the locale. The one part that takes practice is reading chrony's source table to confirm the clock actually locked onto something instead of just reaching for it.</p>

<h2 id="chrony" class="pp-h2">Configure chrony</h2>

<p>Back up the config, strip the default pool and server lines, and add the two sources the ticket asked for. <code>iburst</code> makes the first sync happen in seconds instead of minutes.</p>

<div class="pp-code"><div class="pp-code-head"><div class="pp-code-dots"><div class="pp-code-dot" style="background:#ff5f57"></div><div class="pp-code-dot" style="background:#febc2e"></div><div class="pp-code-dot" style="background:#28c840"></div></div><div class="pp-code-lang">bash</div><button class="pp-code-copy" onclick="navigator.clipboard.writeText(this.closest('.pp-code').querySelector('pre').textContent);this.textContent='copied!';setTimeout(()=>this.textContent='copy',1500)">copy</button></div><div class="pp-code-body"><pre>{`sudo cp /etc/chrony.conf /etc/chrony.conf.bak\nsudo sed -i '/^pool /d; /^server /d' /etc/chrony.conf\nsudo bash -c 'cat >> /etc/chrony.conf << EOF\nserver time.cloudflare.com iburst\npool pool.ntp.org iburst\nEOF'\ngrep -E '^pool|^server' /etc/chrony.conf`}</pre></div></div>

<h2 id="verify-sync" class="pp-h2">Verify the sync</h2>

<p>Restart chrony, give it a few seconds, then read the sources and the tracking. In <code>chronyc sources</code>, the marker at the start of a line tells you the state: <code>^*</code> is the selected source, <code>^+</code> is combined in, <code>^-</code> is excluded, and <code>^?</code> is unreachable.</p>

<div class="pp-code"><div class="pp-code-head"><div class="pp-code-dots"><div class="pp-code-dot" style="background:#ff5f57"></div><div class="pp-code-dot" style="background:#febc2e"></div><div class="pp-code-dot" style="background:#28c840"></div></div><div class="pp-code-lang">bash</div><button class="pp-code-copy" onclick="navigator.clipboard.writeText(this.closest('.pp-code').querySelector('pre').textContent);this.textContent='copied!';setTimeout(()=>this.textContent='copy',1500)">copy</button></div><div class="pp-code-body"><pre>{`sudo systemctl enable --now chronyd\nsudo systemctl restart chronyd\nsleep 5\n\nchronyc sources\n# MS Name/IP address       Stratum Poll Reach LastRx Last sample\n# ^* time.cloudflare.com         3    6   377     17   -42us[ -61us] +/- 12ms\n#  the ^* is what you are looking for: this source is selected and in use\nchronyc tracking\n# Stratum     : 4\n# System time : 0.000038 seconds fast of NTP time    <- no longer 4 minutes`}</pre></div></div>

<h2 id="timedatectl" class="pp-h2">timedatectl for time and timezone</h2>

<p>One command shows the whole time picture, including whether the clock is synchronized and NTP is active. Setting the timezone through timedatectl validates the name and fixes the <code>/etc/localtime</code> link for you.</p>

<div class="pp-code"><div class="pp-code-head"><div class="pp-code-dots"><div class="pp-code-dot" style="background:#ff5f57"></div><div class="pp-code-dot" style="background:#febc2e"></div><div class="pp-code-dot" style="background:#28c840"></div></div><div class="pp-code-lang">bash</div><button class="pp-code-copy" onclick="navigator.clipboard.writeText(this.closest('.pp-code').querySelector('pre').textContent);this.textContent='copied!';setTimeout(()=>this.textContent='copy',1500)">copy</button></div><div class="pp-code-body"><pre>{`timedatectl              # local time, timezone, synced?, NTP active?\n\ntimedatectl list-timezones | grep -i new_york\nsudo timedatectl set-timezone America/New_York\n\n# timedatectl also toggles NTP, since it manages chronyd\nsudo timedatectl set-ntp true\ntimedatectl | grep -i ntp`}</pre></div></div>
