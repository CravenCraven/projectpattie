<p><span class="c-light">The ticket:</span> ops1 needs two scripts in <code>/usr/local/bin/</code>, both runnable by the <code>automation</code> group. A <code>diskcheck</code> that reports the usage of any mountpoint passed as an argument and fails cleanly with a non-zero exit code if the mountpoint does not exist. And an <code>adduser_safe</code> that creates a user if they do not already exist, skips them if they do, and appends every action to an audit log.</p>

<p><span class="c-light">The real problem:</span> this is where scripting stops being one-liners. Argument handling, conditionals, exit codes, and logging, done the way a real tool would.</p>

<p><span class="c-light">What we are doing:</span> writing two genuine shell scripts, testing every failure path, not just the happy one.</p>

<h2 id="diskcheck" class="pp-h2">Script one. diskcheck.</h2>

<p>It takes a mountpoint as <code>$1</code>. If none is given, or the path is not actually a mountpoint, it prints a clear error and exits non-zero. Different failures get different exit codes so a caller can tell them apart.</p>

<div class="pp-code"><div class="pp-code-head"><div class="pp-code-dots"><div class="pp-code-dot"></div><div class="pp-code-dot"></div><div class="pp-code-dot"></div></div><div class="pp-code-lang">bash</div><button class="pp-code-copy" onclick="navigator.clipboard.writeText(this.closest('.pp-code').querySelector('pre').textContent);this.textContent='copied!';setTimeout(()=>this.textContent='copy',1500)">copy</button></div><div class="pp-code-body"><pre>{`sudo bash -c 'cat > /usr/local/bin/diskcheck.sh << "EOF"\n#!/bin/bash\n# diskcheck.sh -- report disk usage for a given mountpoint\n# usage: diskcheck.sh /mountpoint\n\nMOUNT="$1"\n\nif [ -z "$MOUNT" ]; then\n    echo "ERROR: usage: $0 <mountpoint>"\n    exit 1\nfi\n\nif ! mountpoint -q "$MOUNT"; then\n    echo "ERROR: $MOUNT is not a mounted filesystem"\n    exit 2\nfi\n\nUSAGE=$(df -h "$MOUNT" | awk "NR==2 {print \\$5}")\necho "Disk usage at $MOUNT: $USAGE"\nexit 0\nEOF'\n\nsudo chmod 750 /usr/local/bin/diskcheck.sh\nsudo chgrp automation /usr/local/bin/diskcheck.sh\n\n# test every path: valid, invalid, missing arg\n/usr/local/bin/diskcheck.sh / ; echo "exit: $?"\n/usr/local/bin/diskcheck.sh /fakepath ; echo "exit: $?"\n/usr/local/bin/diskcheck.sh ; echo "exit: $?"`}</pre></div></div>

<p><code>-z</code> tests for an empty string, <code>mountpoint -q</code> checks the path is a real mount, and each <code>exit</code> code is distinct so failures are diagnosable.</p>

<h2 id="adduser-safe" class="pp-h2">Script two. adduser_safe.</h2>

<p>Idempotent means running it twice is safe. If the user exists it logs a skip and exits 0. If a named group does not exist it errors. Every outcome is appended to the audit log with a timestamp.</p>

<div class="pp-code"><div class="pp-code-head"><div class="pp-code-dots"><div class="pp-code-dot"></div><div class="pp-code-dot"></div><div class="pp-code-dot"></div></div><div class="pp-code-lang">bash</div><button class="pp-code-copy" onclick="navigator.clipboard.writeText(this.closest('.pp-code').querySelector('pre').textContent);this.textContent='copied!';setTimeout(()=>this.textContent='copy',1500)">copy</button></div><div class="pp-code-body"><pre>{`sudo bash -c 'cat > /usr/local/bin/adduser_safe.sh << "EOF"\n#!/bin/bash\n# adduser_safe.sh -- idempotent user creation with an audit trail\n# usage: adduser_safe.sh <username> [group]\n\nLOGFILE="/var/log/user_provisioning.log"\nUSERNAME="$1"\nGROUP="$2"\nTS=$(date "+%Y-%m-%d %H:%M:%S")\n\nif [ -z "$USERNAME" ]; then\n    echo "ERROR: usage: $0 <username> [group]"\n    exit 1\nfi\n\nif id "$USERNAME" &>/dev/null; then\n    echo "$TS SKIPPED: user $USERNAME already exists" >> "$LOGFILE"\n    echo "User $USERNAME already exists. Skipping."\n    exit 0\nfi\n\nif [ -n "$GROUP" ]; then\n    if ! getent group "$GROUP" &>/dev/null; then\n        echo "$TS ERROR: group $GROUP does not exist" >> "$LOGFILE"\n        echo "ERROR: group $GROUP does not exist"\n        exit 2\n    fi\n    useradd -m -G "$GROUP" "$USERNAME"\n    echo "$TS CREATED: $USERNAME (added to $GROUP)" >> "$LOGFILE"\nelse\n    useradd -m "$USERNAME"\n    echo "$TS CREATED: $USERNAME" >> "$LOGFILE"\nfi\nexit 0\nEOF'\n\nsudo chmod +x /usr/local/bin/adduser_safe.sh\nsudo touch /var/log/user_provisioning.log\nsudo chgrp automation /var/log/user_provisioning.log\nsudo chmod 660 /var/log/user_provisioning.log\n\n# test: create, then re-run (skip), then missing arg, then bad group\nsudo /usr/local/bin/adduser_safe.sh testuser_a developers\nsudo /usr/local/bin/adduser_safe.sh testuser_a developers\nsudo /usr/local/bin/adduser_safe.sh\nsudo /usr/local/bin/adduser_safe.sh testuser_b nonexistent_group\nsudo cat /var/log/user_provisioning.log\nsudo userdel -r testuser_a 2>/dev/null`}</pre></div></div>

<p><code>id "$USERNAME" &>/dev/null</code> is the existence check, its output thrown away because you only care about the exit status. <code>-n</code> tests for a non-empty string, the mirror of <code>-z</code>.</p>

<h2 id="while-loop" class="pp-h2">While loop with a threshold</h2>

<p>A default value with <code>$&#123;2:-80&#125;</code> means the second argument is optional and falls back to 80.</p>

<div class="pp-code"><div class="pp-code-head"><div class="pp-code-dots"><div class="pp-code-dot"></div><div class="pp-code-dot"></div><div class="pp-code-dot"></div></div><div class="pp-code-lang">bash</div><button class="pp-code-copy" onclick="navigator.clipboard.writeText(this.closest('.pp-code').querySelector('pre').textContent);this.textContent='copied!';setTimeout(()=>this.textContent='copy',1500)">copy</button></div><div class="pp-code-body"><pre>{`cat > ~/disk_watch.sh << 'EOF'\n#!/bin/bash\nMOUNT="$1"\nTHRESHOLD="\${2:-80}"\nfor i in 1 2 3; do\n    USAGE=$(df --output=pcent "$MOUNT" 2>/dev/null | tail -1 | tr -d ' %')\n    if [ "$USAGE" -ge "$THRESHOLD" ]; then\n        echo "WARN: $MOUNT at \${USAGE}% (threshold $THRESHOLD%)"\n    else\n        echo "OK: $MOUNT at \${USAGE}%"\n    fi\n    sleep 1\ndone\nEOF\nchmod +x ~/disk_watch.sh\n~/disk_watch.sh / 50`}</pre></div></div>
