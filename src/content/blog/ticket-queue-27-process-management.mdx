<p>Monitoring is screaming: load average 18.42 on a four-core box, which means work is stacking up nine deep for every core it has. <code>top</code> points at two processes owned by dbadmin1, a <code>find /</code> that got stuck and a <code>dd</code> that ran away, and dbadmin1 is not answering Slack. ops1 wants them gone, but gone carefully: graceful first, force only if they ignore it, because whether they die clean is itself a clue for the postmortem.</p>

<p>The instinct under pressure is <code>kill -9</code> on everything, and that is the mistake. A graceful signal gives a process the chance to flush its buffers and release its locks. Force is what you escalate to when it refuses, not what you open with. The rest of the ticket is reprioritizing a backup so it stops elbowing production, and grabbing a top-consumers snapshot for the incident.</p>

<p>Niceness runs from -20 to +19, where lower means more CPU and higher means nicer to everyone else. Any user can raise their own niceness, but only root can lower it below 0. Set it at start with <code>nice</code>, change it on a running process with <code>renice</code>.</p>

<h2 id="find" class="pp-h2">Find the runaway processes</h2>

<p>Sort by CPU, then narrow to the one user. <code>pgrep</code> is cleaner than grepping <code>ps</code>, which matches the word anywhere on the line including arguments.</p>

<div class="pp-code"><div class="pp-code-head"><div class="pp-code-dots"><div class="pp-code-dot"></div><div class="pp-code-dot"></div><div class="pp-code-dot"></div></div><div class="pp-code-lang">bash</div><button class="pp-code-copy" onclick="navigator.clipboard.writeText(this.closest('.pp-code').querySelector('pre').textContent);this.textContent='copied!';setTimeout(()=>this.textContent='copy',1500)">copy</button></div><div class="pp-code-body"><pre>{`ps -u dbadmin1 -o pid,%cpu,stat,command --sort=-%cpu\n#   PID  %CPU STAT COMMAND\n#  4820  99.7 R    dd if=/dev/zero of=/dev/null\n#  4791  97.3 R    find / -type f\n\npgrep -u dbadmin1 -a    # confirm the owner and the exact PIDs\n# 4791 find / -type f\n# 4820 dd if=/dev/zero of=/dev/null`}</pre></div></div>

<h2 id="kill" class="pp-h2">Graceful termination, then escalate</h2>

<p>Send SIGTERM first, wait, then send SIGKILL only to whatever ignored it.</p>

<div class="pp-code"><div class="pp-code-head"><div class="pp-code-dots"><div class="pp-code-dot"></div><div class="pp-code-dot"></div><div class="pp-code-dot"></div></div><div class="pp-code-lang">bash</div><button class="pp-code-copy" onclick="navigator.clipboard.writeText(this.closest('.pp-code').querySelector('pre').textContent);this.textContent='copied!';setTimeout(()=>this.textContent='copy',1500)">copy</button></div><div class="pp-code-body"><pre>{`# graceful, SIGTERM is the default\nsudo pkill -TERM -u dbadmin1 dd\nsudo pkill -TERM -u dbadmin1 find\nsleep 5\npgrep -u dbadmin1 -a\n\n# still alive? force it\nsudo pkill -KILL -u dbadmin1 dd\npgrep -u dbadmin1 -a || echo "all clear"`}</pre></div></div>

<div class="pp-note"><strong>note:</strong> <code>kill PID</code> targets one numeric PID, <code>pkill PATTERN</code> matches by name with filters like <code>-u user</code>, and <code>killall NAME</code> matches an exact command name. <code>kill -0 PID</code> sends no signal at all, it just checks whether the process still exists.</div>

<h2 id="renice" class="pp-h2">Renice a running process</h2>

<p>Niceness is a live kernel attribute, so you can change it without restarting anything.</p>

<div class="pp-code"><div class="pp-code-head"><div class="pp-code-dots"><div class="pp-code-dot"></div><div class="pp-code-dot"></div><div class="pp-code-dot"></div></div><div class="pp-code-lang">bash</div><button class="pp-code-copy" onclick="navigator.clipboard.writeText(this.closest('.pp-code').querySelector('pre').textContent);this.textContent='copied!';setTimeout(()=>this.textContent='copy',1500)">copy</button></div><div class="pp-code-body"><pre>{`pgrep -u alice -a yes         # find the PID, say 4221\nps -o pid,ni,comm -p 4221    # current niceness\nsudo renice -n 15 -p 4221    # much lower priority\nps -o pid,ni,comm -p 4221\n\n# or renice every process owned by a user\nsudo renice -n 10 -u alice`}</pre></div></div>

<div class="pp-code"><div class="pp-code-head"><div class="pp-code-dots"><div class="pp-code-dot"></div><div class="pp-code-dot"></div><div class="pp-code-dot"></div></div><div class="pp-code-lang">bash</div><button class="pp-code-copy" onclick="navigator.clipboard.writeText(this.closest('.pp-code').querySelector('pre').textContent);this.textContent='copied!';setTimeout(()=>this.textContent='copy',1500)">copy</button></div><div class="pp-code-body"><pre>{`# niced and detached: run as alice, ignore SIGHUP, start at +15, background it\nsudo -u alice nohup nice -n 15 /usr/local/bin/nightly_backup.sh > /tmp/backup.log 2>&1 &\npgrep -u alice -a nightly_backup\nps -o pid,ni,user,comm -C nightly_backup.sh    # NI should be 15`}</pre></div></div>
