<h2 class="pp-h2" id="what-we-re-building">What we're building</h2>

<p>By the end of this you'll have a working Pomodoro timer that:</p>

<ul><li>Counts down focus and break sessions with a glowing progress ring</li><li>Switches between <strong>8 color themes</strong> (cyberpunk, neon, synthwave, and more)</li><li>Plays a chime when time's up, with a volume slider and optional ticking</li><li>Tracks what you study with subjects, tasks, and a "what are you working on?" note</li><li>Shows an analytics dashboard with charts and a GitHub-style activity heatmap</li><li>Saves everything in your browser so your data survives a refresh</li><li>Installs as an app on your phone or desktop (it's a PWA)</li></ul>

<p>It's one HTML file. No <code>npm install</code>, no webpack, no React. If you know a little HTML and CSS, you can follow along.</p>

<p>We build it in seven stages. Each stage is a complete, working version you can run, so you're never staring at 700 lines wondering what does what.</p>

<div class="pp-note"><strong>Want the finished file?</strong> The whole thing lives in one file: <a href="/pomodoro.html">the complete <code>index.html</code></a>. Open it to run it, or View Source to read every line in one place. The rest of this post is how you get there from nothing.</div>

<div class="pp-note"><strong>The Pomodoro Technique</strong>, if you're new to it: work in focused 25-minute blocks ("pomodoros"), take a 5-minute break after each, and a longer 15-minute break after every four. It's a simple way to make big tasks feel manageable.</div>

<p><strong>What's happening here:</strong></p>

<ul><li><code>remaining</code> holds the seconds left. We start with <code>25 * 60</code> = 1500 seconds.</li><li><code>setInterval(fn, 1000)</code> is the heart of any timer. It runs a function once per second, and we use it to subtract 1 from <code>remaining</code> and redraw.</li><li><code>clearInterval(timerId)</code> stops that loop. We call it when we pause or when we hit zero.</li><li><code>format()</code> converts 1500 into <code>"25:00"</code>. The <code>padStart(2, '0')</code> adds a leading zero so we get <code>05</code> instead of <code>5</code>.</li></ul>

<h2 class="pp-h2" id="stage-2-the-progress-ring">Stage 2: The progress ring</h2>

<p>Now the JavaScript. We calculate the circumference and update the ring's offset each second. Add this near the top of your <code>&lt;script&gt;</code>:</p>

<div class="pp-code"><div class="pp-code-head"><div class="pp-code-dots"><div class="pp-code-dot"></div><div class="pp-code-dot"></div><div class="pp-code-dot"></div></div><div class="pp-code-lang">javascript</div><button class="pp-code-copy" onclick="navigator.clipboard.writeText(this.closest('.pp-code').querySelector('pre').textContent);this.textContent='copied!';setTimeout(()=>this.textContent='copy',1500)">copy</button></div><div class="pp-code-body"><pre>{`const RADIUS = 110;\nconst CIRCUMFERENCE = 2 * Math.PI * RADIUS;   // ≈ 691\nconst total = 25 * 60;   // the full duration, used to calculate the fraction`}</pre></div></div>

<p>Then update <code>render()</code> to also move the ring:</p>

<div class="pp-code"><div class="pp-code-head"><div class="pp-code-dots"><div class="pp-code-dot"></div><div class="pp-code-dot"></div><div class="pp-code-dot"></div></div><div class="pp-code-lang">javascript</div><button class="pp-code-copy" onclick="navigator.clipboard.writeText(this.closest('.pp-code').querySelector('pre').textContent);this.textContent='copied!';setTimeout(()=>this.textContent='copy',1500)">copy</button></div><div class="pp-code-body"><pre>{`function render() {\n  document.getElementById('time').textContent = format(remaining);\n\n  const ring = document.getElementById('ring');\n  ring.style.strokeDasharray = CIRCUMFERENCE;\n  // As remaining shrinks, the offset grows, "emptying" the ring\n  const offset = CIRCUMFERENCE * (1 - remaining / total);\n  ring.style.strokeDashoffset = offset;\n}`}</pre></div></div>

<p><strong>How it works.</strong> <code>stroke-dasharray</code> set to the full circumference makes one dash that wraps the whole circle. <code>stroke-dashoffset</code> then pushes that dash around. Offset 0 means the ring is full; offset equal to the circumference means it's empty. We compute the offset from how much time is left. The <code>transition</code> in the CSS animates it smoothly instead of jumping.</p>

<h2 class="pp-h2" id="stage-4-sound-when-time-s-up">Stage 4: Sound when time's up</h2>

<p>We want a chime, but shipping an audio file is overkill. The <strong>Web Audio API</strong> generates tones in code. Here's a function that plays a three-note chime:</p>

<div class="pp-code"><div class="pp-code-head"><div class="pp-code-dots"><div class="pp-code-dot"></div><div class="pp-code-dot"></div><div class="pp-code-dot"></div></div><div class="pp-code-lang">javascript</div><button class="pp-code-copy" onclick="navigator.clipboard.writeText(this.closest('.pp-code').querySelector('pre').textContent);this.textContent='copied!';setTimeout(()=>this.textContent='copy',1500)">copy</button></div><div class="pp-code-body"><pre>{`let audioCtx = null;\n\nfunction getAudio() {\n  // Browsers require a user click before audio can start,\n  // so we create the context lazily on first use.\n  if (!audioCtx) {\n    audioCtx = new (window.AudioContext || window.webkitAudioContext)();\n  }\n  if (audioCtx.state === 'suspended') audioCtx.resume();\n  return audioCtx;\n}\n\nfunction beep() {\n  const ctx = getAudio();\n  const notes = [880, 1108, 1318];   // an ascending chord (A5, C#6, E6)\n\n  notes.forEach((frequency, i) => {\n    const oscillator = ctx.createOscillator();\n    const gain = ctx.createGain();\n    oscillator.connect(gain);\n    gain.connect(ctx.destination);\n\n    oscillator.type = 'sine';\n    oscillator.frequency.value = frequency;\n\n    const startTime = ctx.currentTime + i * 0.18;   // stagger each note\n    // Fade in quickly, then fade out — avoids an ugly click\n    gain.gain.setValueAtTime(0, startTime);\n    gain.gain.linearRampToValueAtTime(0.3, startTime + 0.02);\n    gain.gain.exponentialRampToValueAtTime(0.001, startTime + 0.35);\n\n    oscillator.start(startTime);\n    oscillator.stop(startTime + 0.35);\n  });\n}`}</pre></div></div>

<p>Then call <code>beep()</code> at the top of <code>onComplete()</code>. Now every session ends with a chime.</p>

<p><strong>How it works.</strong> An <em>oscillator</em> generates a raw tone at a given frequency. A <em>gain node</em> controls its volume. Ramp the gain up fast and down slow and each note sounds like a soft bell instead of a harsh blip. Three notes slightly apart make a chord.</p>

<div class="pp-note"><strong>Tip.</strong> Browsers block audio until the user interacts with the page. That's why <code>getAudio()</code> builds the context on demand and calls <code>resume()</code>. By the time a session ends the user has already clicked Start, so audio is unlocked.</div>

<p><strong><code>manifest.json</code></strong> tells the browser what the app is called and what icon to use:</p>

<p><strong><code>sw.js</code></strong> is a service worker. It caches your files so the app loads with no internet:</p>

<div class="pp-code"><div class="pp-code-head"><div class="pp-code-dots"><div class="pp-code-dot"></div><div class="pp-code-dot"></div><div class="pp-code-dot"></div></div><div class="pp-code-lang">javascript</div><button class="pp-code-copy" onclick="navigator.clipboard.writeText(this.closest('.pp-code').querySelector('pre').textContent);this.textContent='copied!';setTimeout(()=>this.textContent='copy',1500)">copy</button></div><div class="pp-code-body"><pre>{`const CACHE = 'pomo-v1';\nconst ASSETS = ['./index.html', './manifest.json'];\n\nself.addEventListener('install', e => {\n  e.waitUntil(caches.open(CACHE).then(c => c.addAll(ASSETS)));\n});\n\nself.addEventListener('fetch', e => {\n  e.respondWith(\n    caches.match(e.request).then(cached => cached || fetch(e.request))\n  );\n});`}</pre></div></div>

<p>Then link them in your <code>&lt;head&gt;</code> and register the service worker:</p>

<h2 class="pp-h2" id="publishing-it-for-free">Publishing it for free</h2>

<p>You don't need a server. Three options, all free, all give you the HTTPS URL the PWA install needs.</p>

<h3 class="pp-h3">Netlify Drop (fastest)</h3>

<ol><li>Go to <strong>app.netlify.com/drop</strong>.</li><li>Drag your project folder, or a zip of it, onto the drop zone.</li><li>A few seconds later you have a live URL like <code>your-site.netlify.app</code>.</li></ol>

<p>No account needed for that first URL, but the anonymous version is temporary. Make a free account when prompted to claim it and keep it. After that you can rename it under Site settings, and you redeploy by dragging a new folder onto the Deploys page.</p>

<h3 class="pp-h3">Cloudflare Pages</h3>

<ol><li>Go to <strong>dash.cloudflare.com</strong>, open <strong>Workers &amp; Pages</strong>, and click <strong>Create application</strong>.</li><li>Choose <strong>Upload your static files</strong> (or the Pages "Get started" link for direct upload).</li><li>Name the project <em>first</em>. Leave it blank and Cloudflare hands you something like <code>plain-bar-8396</code>, and there's no clean rename afterward, you just redeploy.</li><li>Drag your unzipped folder in and hit Deploy.</li></ol>

<p>You land on <code>your-project.pages.dev</code>. The free tier has no bandwidth cap, which is the main reason to reach for it.</p>

<h3 class="pp-h3">GitHub Pages</h3>

<ol><li>Create a new <strong>public</strong> repo and put all your files in the root.</li><li>In the repo, go to <strong>Settings</strong>, then <strong>Pages</strong>.</li><li>Under Source, pick <strong>Deploy from a branch</strong>, choose <code>main</code> and <code>/ (root)</code>, and Save.</li><li>A minute later it's live at <code>https://username.github.io/reponame</code>.</li></ol>

<p>Free GitHub Pages only serves public repos, so skip it for anything you want kept private.</p>

<h2 class="pp-h2" id="where-to-go-next">Where to go next</h2>

<p>That's a working app, built from scratch, that you understand top to bottom. A few ways to take it further:</p>

<ul><li><strong>Multiple themes.</strong> Store color values in CSS variables (<code>--accent: #00ffc8</code>) and swap them with a class on <code>&lt;body&gt;</code>. That's how the full version does its 8 themes.</li><li><strong>Saved presets.</strong> You can already set any duration (Stage 3.5). Go further and let users <em>save</em> named combos, a "Deep Work" 50/10, a "Sprint" 15/3, switched with one click.</li><li><strong>Ambient sounds.</strong> Loop rain or café noise during focus sessions with the same Web Audio API.</li><li><strong>Data export.</strong> Turn the <code>log</code> array into a CSV string and trigger a download, so users can crunch their habits in a spreadsheet.</li><li><strong>A real streak counter.</strong> Compare today's date to the last active date and count consecutive study days.</li></ul>

<p>The point of building with plain HTML, CSS, and JavaScript is that nothing is hidden. Every line is yours to read and change. Open the file, change a color, break something, fix it. That's how it sticks.</p>
