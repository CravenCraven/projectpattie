<p><span class="c-light">The ticket:</span> the web service runs but does not survive reboots. A kernel-patch reboot last week left httpd down and cost two hours. webadmin wants four things. Install httpd and enable it on boot in one command. Mask an old ntp-style daemon so it can never start, even by accident. Show how to read httpd logs through <code>journalctl</code> instead of digging in <code>/var/log/httpd/</code>. And confirm the default boot target is text, not a GUI.</p>

<p><span class="c-light">The real problem:</span> starting a service and enabling it are two different things, and the reboot survival everyone assumes comes from <code>enable</code>, not <code>start</code>. Masking is also stronger than disabling, and the difference matters here.</p>

<p><span class="c-light">What we are doing:</span> the service lifecycle with <code>systemctl</code>, log reading with <code>journalctl</code>, and boot targets.</p>

<p>Targets replaced the old runlevels. <code>multi-user.target</code> is text and networked, the old runlevel 3. <code>graphical.target</code> is the GUI, runlevel 5. <code>rescue.target</code> is single user, and <code>emergency.target</code> is minimal recovery. This server should sit on multi-user so no GUI ever loads.</p>

<h2 id="enable" class="pp-h2">Install and enable httpd in one shot</h2>

<p>The key command is <code>enable --now</code>. <code>enable</code> makes it start at boot, and <code>--now</code> also starts it immediately, so you do not need a separate <code>start</code>. This is the shortcut the exam expects you to know cold.</p>

<div class="pp-code"><div class="pp-code-head"><div class="pp-code-dots"><div class="pp-code-dot" style="background:#ff5f57"></div><div class="pp-code-dot" style="background:#febc2e"></div><div class="pp-code-dot" style="background:#28c840"></div></div><div class="pp-code-lang">bash</div><button class="pp-code-copy" onclick="navigator.clipboard.writeText(this.closest('.pp-code').querySelector('pre').textContent);this.textContent='copied!';setTimeout(()=>this.textContent='copy',1500)">copy</button></div><div class="pp-code-body"><pre>{`sudo dnf install -y httpd\nsudo systemctl enable --now httpd\n\nsystemctl is-active httpd     # active\nsystemctl is-enabled httpd    # enabled\nsudo systemctl status httpd`}</pre></div></div>

<h2 id="mask" class="pp-h2">Mask the daemon that should never run</h2>

<p>Masking symlinks the unit to <code>/dev/null</code>, so it cannot start at all, not even when something else depends on it. That is stronger than <code>disable</code>, which only stops auto-start but still allows a manual start. Practice on chronyd, then unmask it, since you actually want chrony later.</p>

<div class="pp-code"><div class="pp-code-head"><div class="pp-code-dots"><div class="pp-code-dot" style="background:#ff5f57"></div><div class="pp-code-dot" style="background:#febc2e"></div><div class="pp-code-dot" style="background:#28c840"></div></div><div class="pp-code-lang">bash</div><button class="pp-code-copy" onclick="navigator.clipboard.writeText(this.closest('.pp-code').querySelector('pre').textContent);this.textContent='copied!';setTimeout(()=>this.textContent='copy',1500)">copy</button></div><div class="pp-code-body"><pre>{`sudo systemctl mask chronyd\nsudo systemctl start chronyd    # fails: Unit chronyd.service is masked\n\nsudo systemctl unmask chronyd\nsudo systemctl start chronyd`}</pre></div></div>

<h2 id="journalctl" class="pp-h2">Read the logs with journalctl</h2>

<p>The journal replaces hunting through log files. Filter by unit, count, priority, boot, and time.</p>

<h2 id="units" class="pp-h2">Inspect and override unit files</h2>

<p>Never edit a shipped unit file directly. <code>systemctl edit</code> creates a drop-in override, and after any unit change you reload the daemon.</p>

<div class="pp-code"><div class="pp-code-head"><div class="pp-code-dots"><div class="pp-code-dot" style="background:#ff5f57"></div><div class="pp-code-dot" style="background:#febc2e"></div><div class="pp-code-dot" style="background:#28c840"></div></div><div class="pp-code-lang">bash</div><button class="pp-code-copy" onclick="navigator.clipboard.writeText(this.closest('.pp-code').querySelector('pre').textContent);this.textContent='copied!';setTimeout(()=>this.textContent='copy',1500)">copy</button></div><div class="pp-code-body"><pre>{`systemctl cat httpd\nsudo systemctl edit httpd    # creates a drop-in override.conf\nsudo systemctl daemon-reload\nsudo systemctl restart httpd`}</pre></div></div>
