<p>nfsadmin liked the NFS share from yesterday but not the idea of every box in the fleet holding it mounted around the clock. What they want is on-demand: the share appears the instant someone touches the path, and quietly unmounts once it goes idle. That is autofs, and the ticket asks for it two ways, an indirect map that manages <code>/shares/team</code>, and a direct map that mounts <code>/data/projects</code> with no parent directory to manage.</p>

<p>Indirect and direct maps do nearly the same job and read nearly the same on paper, which is exactly why people mix them up. The difference lives in two precise spots, the <code>auto.master</code> line and the paths inside the map file, and getting either one wrong is the usual reason a mount silently never happens.</p>

<h2 id="concept-review" class="pp-h2">Concept review. The map files, indirect versus direct.</h2>

<div class="pp-code"><div class="pp-code-head"><div class="pp-code-dots"><div class="pp-code-dot" style="background:#ff5f57"></div><div class="pp-code-dot" style="background:#febc2e"></div><div class="pp-code-dot" style="background:#28c840"></div></div><div class="pp-code-lang">bash</div><button class="pp-code-copy" onclick="navigator.clipboard.writeText(this.closest('.pp-code').querySelector('pre').textContent);this.textContent='copied!';setTimeout(()=>this.textContent='copy',1500)">copy</button></div><div class="pp-code-body"><pre>{`man 5 auto.master\nman 5 autofs`}</pre></div></div>

<p><code>/etc/auto.master</code> is the top file. It lists mountpoints and points each at a map file that holds the actual mounts. An indirect map manages a set of subdirectories under one parent, good when several shares live under a common directory. A direct map handles specific full paths that do not share a parent.</p>

<div class="pp-code"><div class="pp-code-head"><div class="pp-code-dots"><div class="pp-code-dot" style="background:#ff5f57"></div><div class="pp-code-dot" style="background:#febc2e"></div><div class="pp-code-dot" style="background:#28c840"></div></div><div class="pp-code-lang">autofs hierarchy</div><button class="pp-code-copy" onclick="navigator.clipboard.writeText(this.closest('.pp-code').querySelector('pre').textContent);this.textContent='copied!';setTimeout(()=>this.textContent='copy',1500)">copy</button></div><div class="pp-code-body"><pre>{`/etc/auto.master        the master, lists mountpoints and their maps\n  -> /etc/auto.shares   an indirect map (parent dir plus sub-mounts)\n  -> /etc/auto.direct   a direct map (full path mounts)\n\n# in auto.master:\n/shares /etc/auto.shares    indirect, parent is /shares\n/-      /etc/auto.direct    direct, the /- is the literal indicator`}</pre></div></div>

<h2 id="indirect" class="pp-h2">The indirect map</h2>

<p>The map line names a subdirectory, options, and the source. The final path becomes the parent from auto.master plus the subdirectory, here <code>/shares/team</code>.</p>

<div class="pp-code"><div class="pp-code-head"><div class="pp-code-dots"><div class="pp-code-dot" style="background:#ff5f57"></div><div class="pp-code-dot" style="background:#febc2e"></div><div class="pp-code-dot" style="background:#28c840"></div></div><div class="pp-code-lang">bash</div><button class="pp-code-copy" onclick="navigator.clipboard.writeText(this.closest('.pp-code').querySelector('pre').textContent);this.textContent='copied!';setTimeout(()=>this.textContent='copy',1500)">copy</button></div><div class="pp-code-body"><pre>{`sudo tee /etc/auto.shares << 'EOF'\nteam   -rw,sync   localhost:/srv/nfsshare\nEOF\n\nsudo cp /etc/auto.master /etc/auto.master.bak\necho "/shares /etc/auto.shares" | sudo tee -a /etc/auto.master`}</pre></div></div>

<h2 id="direct" class="pp-h2">The direct map</h2>

<p>A direct map is different in two places. The auto.master line uses the literal <code>/-</code> instead of a parent path, and the map file uses absolute paths on each line instead of relative subdirectories.</p>

<div class="pp-code"><div class="pp-code-head"><div class="pp-code-dots"><div class="pp-code-dot" style="background:#ff5f57"></div><div class="pp-code-dot" style="background:#febc2e"></div><div class="pp-code-dot" style="background:#28c840"></div></div><div class="pp-code-lang">bash</div><button class="pp-code-copy" onclick="navigator.clipboard.writeText(this.closest('.pp-code').querySelector('pre').textContent);this.textContent='copied!';setTimeout(()=>this.textContent='copy',1500)">copy</button></div><div class="pp-code-body"><pre>{`sudo tee /etc/auto.direct << 'EOF'\n/data/projects   -rw,sync   localhost:/srv/nfsshare\nEOF\n\necho "/- /etc/auto.direct" | sudo tee -a /etc/auto.master`}</pre></div></div>

<h2 id="activate" class="pp-h2">Activate autofs and test</h2>

<p>Start the service, then trigger each mount just by looking into the path. autofs creates and mounts it on demand.</p>

<div class="pp-code"><div class="pp-code-head"><div class="pp-code-dots"><div class="pp-code-dot" style="background:#ff5f57"></div><div class="pp-code-dot" style="background:#febc2e"></div><div class="pp-code-dot" style="background:#28c840"></div></div><div class="pp-code-lang">bash</div><button class="pp-code-copy" onclick="navigator.clipboard.writeText(this.closest('.pp-code').querySelector('pre').textContent);this.textContent='copied!';setTimeout(()=>this.textContent='copy',1500)">copy</button></div><div class="pp-code-body"><pre>{`sudo systemctl enable --now autofs\nsudo systemctl reload autofs    # after editing maps\n\n# indirect: listing the path triggers the mount\nls /shares/team\nmount | grep team\ncat /shares/team/welcome.txt\n\n# direct: same idea\nls /data/projects\nmount | grep projects`}</pre></div></div>

<h2 id="timeout" class="pp-h2">Idle timeout</h2>

<p>The default idle timeout is five minutes. Access a path and it mounts, leave it alone and autofs unmounts it. You can tune the timeout in auto.master.</p>

<div class="pp-code"><div class="pp-code-head"><div class="pp-code-dots"><div class="pp-code-dot" style="background:#ff5f57"></div><div class="pp-code-dot" style="background:#febc2e"></div><div class="pp-code-dot" style="background:#28c840"></div></div><div class="pp-code-lang">bash</div><button class="pp-code-copy" onclick="navigator.clipboard.writeText(this.closest('.pp-code').querySelector('pre').textContent);this.textContent='copied!';setTimeout(()=>this.textContent='copy',1500)">copy</button></div><div class="pp-code-body"><pre>{`ls /shares/team\nmount | grep team          # mounted\n# leave it idle past the timeout and it unmounts on its own\n\n# set a custom timeout in auto.master:\n# /shares /etc/auto.shares --timeout=60`}</pre></div></div>
