<p><span class="c-light">The ticket:</span> long-running analytics queries are getting OOM-killed during nightly batch runs. Until more RAM is approved, dbadmin1 needs swap as a buffer. Add a 512MB swap file at <code>/extraswap</code> immediately, no reboot, and make it persistent. Also activate the swap partition <code>/dev/sdb2</code> from the partitioning ticket, and make the partition used first because it is slightly faster.</p>

<p><span class="c-light">The real problem:</span> swap is straightforward until you need priority and persistence at the same time. Both pieces have to survive a reboot, and the faster device should win.</p>

<p><span class="c-light">What we are doing:</span> adding swap as both a file and a partition, setting priority, and persisting both.</p>

<h2 id="concept-review" class="pp-h2">Concept review. What swap is and how it is used.</h2>

<div class="pp-code"><div class="pp-code-head"><div class="pp-code-dots"><div class="pp-code-dot"></div><div class="pp-code-dot"></div><div class="pp-code-dot"></div></div><div class="pp-code-lang">bash</div><button class="pp-code-copy" onclick="navigator.clipboard.writeText(this.closest('.pp-code').querySelector('pre').textContent);this.textContent='copied!';setTimeout(()=>this.textContent='copy',1500)">copy</button></div><div class="pp-code-body"><pre>{`man mkswap swapon swapoff`}</pre></div></div>

<p>Swap is overflow for RAM. When physical memory fills, the kernel pages inactive memory out to swap. It is slower than RAM, but it stops the out-of-memory killer from killing your process. You can provide it as a partition, which is slightly faster, or as a file, which is flexible and needs no repartitioning. Priority decides which is used first, where a higher number wins and the default is negative.</p>

<div class="pp-code"><div class="pp-code-head"><div class="pp-code-dots"><div class="pp-code-dot"></div><div class="pp-code-dot"></div><div class="pp-code-dot"></div></div><div class="pp-code-lang">fstab swap entries</div><button class="pp-code-copy" onclick="navigator.clipboard.writeText(this.closest('.pp-code').querySelector('pre').textContent);this.textContent='copied!';setTimeout(()=>this.textContent='copy',1500)">copy</button></div><div class="pp-code-body"><pre>{`/swapfile   none   swap   defaults         0 0\nUUID=xxxx   none   swap   defaults,pri=10  0 0`}</pre></div></div>

<h2 id="swapfile" class="pp-h2">Create the 512MB swap file</h2>

<p>Allocate the space, lock the permissions down before formatting, format it as swap, then turn it on. The permission step matters: if the swap file is world readable, <code>swapon</code> refuses it.</p>

<div class="pp-code"><div class="pp-code-head"><div class="pp-code-dots"><div class="pp-code-dot"></div><div class="pp-code-dot"></div><div class="pp-code-dot"></div></div><div class="pp-code-lang">bash</div><button class="pp-code-copy" onclick="navigator.clipboard.writeText(this.closest('.pp-code').querySelector('pre').textContent);this.textContent='copied!';setTimeout(()=>this.textContent='copy',1500)">copy</button></div><div class="pp-code-body"><pre>{`sudo dd if=/dev/zero of=/extraswap bs=1M count=512 status=progress\nsudo chmod 600 /extraswap    # required, or swapon complains about unsafe permissions\nsudo mkswap /extraswap\nsudo swapon /extraswap\nswapon --show\nfree -h`}</pre></div></div>

<h2 id="partition" class="pp-h2">Activate the swap partition</h2>

<p>The partition was already tagged as swap. Format it, then turn it on with a higher priority so it is used before the file.</p>

<div class="pp-code"><div class="pp-code-head"><div class="pp-code-dots"><div class="pp-code-dot"></div><div class="pp-code-dot"></div><div class="pp-code-dot"></div></div><div class="pp-code-lang">bash</div><button class="pp-code-copy" onclick="navigator.clipboard.writeText(this.closest('.pp-code').querySelector('pre').textContent);this.textContent='copied!';setTimeout(()=>this.textContent='copy',1500)">copy</button></div><div class="pp-code-body"><pre>{`sudo mkswap /dev/sdb2\nsudo blkid /dev/sdb2\nsudo swapon --priority 10 /dev/sdb2\nswapon --show    # two swap devices now, with different priorities`}</pre></div></div>

<h2 id="persist" class="pp-h2">Make both persistent in fstab</h2>

<p>Back up fstab, then add both entries. Use the UUID for the partition so it survives device renaming, and set its priority in the options.</p>

<div class="pp-code"><div class="pp-code-head"><div class="pp-code-dots"><div class="pp-code-dot"></div><div class="pp-code-dot"></div><div class="pp-code-dot"></div></div><div class="pp-code-lang">bash</div><button class="pp-code-copy" onclick="navigator.clipboard.writeText(this.closest('.pp-code').querySelector('pre').textContent);this.textContent='copied!';setTimeout(()=>this.textContent='copy',1500)">copy</button></div><div class="pp-code-body"><pre>{`sudo cp /etc/fstab /etc/fstab.bak.$(date +%Y%m%d)\n\necho "/extraswap   none   swap   defaults         0 0" | sudo tee -a /etc/fstab\n\nSWAP_UUID=$(sudo blkid -s UUID -o value /dev/sdb2)\necho "UUID=$SWAP_UUID   none   swap   defaults,pri=10   0 0" | sudo tee -a /etc/fstab\ntail -5 /etc/fstab`}</pre></div></div>

<h2 id="test" class="pp-h2">Test fstab without rebooting</h2>

<p>Turn everything off, then let fstab turn it back on. If this works, the reboot will too.</p>

<div class="pp-code"><div class="pp-code-head"><div class="pp-code-dots"><div class="pp-code-dot"></div><div class="pp-code-dot"></div><div class="pp-code-dot"></div></div><div class="pp-code-lang">bash</div><button class="pp-code-copy" onclick="navigator.clipboard.writeText(this.closest('.pp-code').querySelector('pre').textContent);this.textContent='copied!';setTimeout(()=>this.textContent='copy',1500)">copy</button></div><div class="pp-code-body"><pre>{`sudo swapoff -a\nswapon --show    # empty\n\nsudo swapon -a   # activates everything marked swap in fstab\nswapon --show    # both back\nfree -h`}</pre></div></div>

<h2 id="swappiness" class="pp-h2">Tune swappiness</h2>

<p>Swappiness controls how eagerly the kernel swaps, from 0 to 100. For a database workload you usually lower it so the box uses RAM longer before swapping.</p>

<div class="pp-code"><div class="pp-code-head"><div class="pp-code-dots"><div class="pp-code-dot"></div><div class="pp-code-dot"></div><div class="pp-code-dot"></div></div><div class="pp-code-lang">bash</div><button class="pp-code-copy" onclick="navigator.clipboard.writeText(this.closest('.pp-code').querySelector('pre').textContent);this.textContent='copied!';setTimeout(()=>this.textContent='copy',1500)">copy</button></div><div class="pp-code-body"><pre>{`cat /proc/sys/vm/swappiness\nsudo sysctl vm.swappiness=10\n\n# make it persistent\necho "vm.swappiness = 10" | sudo tee /etc/sysctl.d/99-server1-swap.conf\nsudo sysctl --system | grep swappiness`}</pre></div></div>
