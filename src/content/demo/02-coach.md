## What it is

A command line tool that corrects my Portuguese writing and classifies every error by kind, so mistakes can be counted and tracked instead of just fixed.

## The plan

Python CLI calling the local model. Its output feeds the Gíria tile, so the error kinds are typed from the start rather than free text.
